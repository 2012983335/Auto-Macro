# Auto-宏

免费高效的 Windows 键鼠操作录制与回放软件。

录下操作、保存记录、一键回放。支持全局快捷键、循环执行和计时设置，适合重复性桌面操作。

## 下载与使用

在 [Releases](../../releases/latest) 下载独立运行版压缩包，解压后启动 `Auto-宏.exe`。已包含 .NET 运行库，无需另外安装。

当前版本适用于 Windows x64，主显示器分辨率须为 **1920×1080**。坐标采用绝对像素，回放时请保持目标窗口的位置和大小与录制一致。

| 快捷键 | 功能 |
| --- | --- |
| F6 | 开始 / 结束录制 |
| F7 | 开始回放 / 暂停 / 继续 |
| F8 | 停止 |
| F9 | 从本轮起点重新执行 |

已有录制内容时，5 秒内再次按 F6 确认覆盖。录制表仅供查看，不支持手动添加或修改操作。

## 功能

- 记录键盘、鼠标点击、滚轮和拖动，保存为 JSON。
- 过滤空闲鼠标移动，保留鼠标按住及 Z/X/C 按住期间的轨迹。
- 通过置顶状态条查看当前状态。
- 保存与读取在后台执行，长记录按可见行显示。
- 设置执行次数和两种结束计时方式。
- 标记计时零点，将之前的操作作为每轮的准备步骤。

循环判定使用当前版本内置的固定区域图像样本，不支持自动适配任意软件。普通重复任务建议先使用单次回放验证。

## 使用说明

录制前设置总时长，按 F6 开始，再按 F6 结束。保存后可用 F7 回放。需要循环准备步骤时，在记录表中选中对应行并标记计时零点。

接收外部脚本通过系统输入发送的操作。回放前请暂停外部连发脚本，避免重复触发。窗口消息形式的输入无法由系统输入钩子录制。目标程序以管理员权限运行时，本工具也需相同权限。

系统负载和目标软件响应会影响回放效果。固定等待间隔不等于与目标软件画面帧同步。

## 构建与验证

使用 .NET 10 SDK：

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o dist/Auto-Macro
```

开发验证：

```powershell
./dist/Auto-Macro/Auto-宏.exe --ui-self-test
./dist/Auto-Macro/Auto-宏.exe --large-axis-test
./checks/acceptance.ps1
```

检查结果输出到对应程序目录。自动验收使用合成输入，不会向目标程序发送真实操作。
